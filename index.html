context_engine

NOU
context_engine.py

Observa continuu desktop-ul in background si clasifica activitatea utilizatorului in categorii: coding, browsing, office, media etc.

  • Detecteaza fereastra activa, clipboard, procese, CPU/RAM in timp real
  • Prezice intentii cu scor de confidenta (invata din comportament)
  • Persista patterns in SQLite - confidenta creste cu repetitia
  • Alimenteaza proactive_interrupt cu predictii

proactive_interrupt

NOU
proactive_interrupt.py

5 detectori activi care recunosc situatii si sugereaza actiuni proactive fara sa fie intrebat.

  • STUCK - blocat 3+ minute pe acelasi task
  • SEQUENCE - fluxuri repetitive de actiuni
  • CLIPBOARD - intentia din continutul clipboard-ului
  • REPEAT - acelasi app deschis des
  • CONTEXT_SHIFT - trecere munca distractie
  • Feedback loop: accepted=true/false ajusteaza confidenta

memory_cortex

NOU
memory_cortex.py

4 tipuri de memorie persistenta pentru LLM-ul din ANA MAX.

  • Episodica - conversatii si context sesiuni
  • Semantica - fapte stabile injectate in prompt
  • Procedurala - abordari care au functionat
  • Error Log - greseli LLM cu prioritate crescatoare
  • Aceeasi greseala de 3x prioritate 100%, blocare preventiva

self_evolving_tool

NOU
self_evolving_tool.py

Auto-reparare si auto-imbunatatire a toolurilor in runtime, fara interventie manuala.

  • Prinde exceptia trimite cod + eroare la LLM (Mistral local)
  • Valideaza fix-ul in sandbox izolat
  • Backup automat aplica daca strica altceva: rollback instant
  • Auto-improve orar: analizeaza fiecare tool si propune optimizari
  • Changelog complet in SQLite

ana_orchestrator

NOU
ana_orchestrator.py

Creierul executor al ANA MAX - transforma un task in limbaj natural intr-o secventa de actiuni concrete.

  • VEDE - screenshot + context curent
  • GANDESTE - analizeaza situatia cu memory_cortex
  • PLANIFICA - genereaza pasi concreti
  • EXECUTA - apeleaza toolurile necesare
  • VERIFICA - screenshot final, confirma rezultatul
  • INVATA - stocheaza in memory_cortex

context_bridge

NOU
context_bridge.py

Memoria dintre sesiuni - agentul nu mai incepe de la zero la fiecare restart.

  • restore_session() la pornire - incarca proiect activ, taskuri incomplete, erori nerezolvate, preferinte editor/shell
  • save_session() la inchidere - salveaza tot starea curenta
  • Persista in ana_memory.db

window_manager

NOU
window_manager.py

Control complet al ferestrelor Windows prin MCP - organizare automata a spatiului de lucru.

  • snap - left / right / maximize
  • tile - grid 21, 22 automat
  • focus - aduce o fereastra in prim-plan
  • list - toate ferestrele deschise
  • close - inchide o fereastra
  • Integrat cu context_engine: 5+ ferestre sugereaza aranjare automata

gemini_proxy

NOU
gemini_proxy_v2.py

Integrare Gemini API pentru suport multi-model (Qwen + Gemini) și performanță extinsă.

  • Proxy local complet pentru Gemini 1.5 Pro / Flash
  • Bypass limitări Ollama pentru sarcini complexe
  • Rutare inteligentă a request-urilor
  • RAG Coding integrat (setup_rag_coding.py)

tool_adapters

NOU
tools/tool_adapters.py

Puntea dintre componentele AI Core si registry-ul MCP. Fara el, modulele ruleaza izolat si nu sunt vizibile clientilor.

  • 7 clase adapter - cate una per componenta
  • Fiecare expune get_definition() si execute(args)
  • Inregistrate automat prin patch in _register_all_tools()
  • Rezultat: toate cele 7 module apar in tools/list MCP
