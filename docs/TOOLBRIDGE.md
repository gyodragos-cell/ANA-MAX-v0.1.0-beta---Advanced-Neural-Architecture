# ToolBridge

ToolBridge orchestrates 90+ local tools for system control, web automation, and code analysis.

## Features

- Routes user intents to appropriate tools
- Validates parameters before execution
- Enforces workspace boundaries
- Provides preflight checks

## Available Tools

- terminal: Execute shell commands
- browser: Web automation
- file_operations: Read/write files
- desktop_workspace: Desktop automation
- web_learning: Scrape and store knowledge
