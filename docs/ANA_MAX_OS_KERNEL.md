# ANA MAX OS Kernel

## Kernel Responsibilities

The runtime kernel schedules work, enforces policies, records events, routes
tools, and manages memory/session boundaries.

## Processes

Agents are processes with roles and process states.

## Syscalls

Tools are syscalls crossing from planning into controlled execution.

## Semantic Filesystem

Memory-backed virtual paths expose semantic data to tools and agents.

## Scheduler

The orchestrator is the scheduler for local, parallel, and distributed tasks.

## Permissions

Policies and OS permissions control tools, memory, nodes, and services.
