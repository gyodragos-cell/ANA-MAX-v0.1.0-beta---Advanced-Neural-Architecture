## ANA MAX OS-3 Agent Roles

### Optimizer Agent
- **Responsibilities**: Performance optimization, code restructuring, capability expansion
- **Modules Used**:
  - Self-Profiling Engine (profile_tools, profile_system, detect_performance_degradation)
  - Self-Structuring Engine (scan_structure, detect_redundancy, propose_reorg)
  - Self-Expanding Skills Layer (detect_missing_capabilities, generate_skill, update_skills_manifest)
- **Artifacts Touched**:
  - docs/PERFORMANCE_LOG.md - Performance profiling results
  - docs/OPTIMIZATIONS.md - Optimization proposals
  - ANA_MAX/memory/performance_profile.json - Machine-readable performance data
  - ANA_MAX/memory/skills_manifest.json - Skills and capabilities manifest
  - docs/TECHNICAL_NOTES.md - Restructuring findings

### Tester Agent
- **Responsibilities**: Error detection, regression testing, safe patching, test execution
- **Modules Used**:
  - Self-Healing Engine (detect_failures, propose_fixes, apply_safe_patch, re_run_tests)
  - Test suite integration (quick, smoke, integration tests)
- **Artifacts Touched**:
  - docs/TEST_REPORT.md - Test results and healing actions
  - docs/CHANGELOG.md - Healing actions and changes
  - Test execution logs and reports

### Documenter Agent
- **Responsibilities**: Knowledge mapping, diagram generation, documentation updates, knowledge graph maintenance
- **Modules Used**:
  - Knowledge Graph Engine (scan_project, build_graph, render_markdown, save_graph)
  - Documentation modules (docs/ directory management)
- **Artifacts Touched**:
  - docs/KNOWLEDGE_GRAPH.md - Knowledge graph documentation
  - ANA_MAX/memory/knowledge_graph.json - Machine-readable graph data
  - docs/TECHNICAL_NOTES.md - Technical notes and patterns
  - Architecture documentation

### Structurer Agent
- **Responsibilities**: Project organization, redundancy detection, safe reorganization, canonical layout enforcement
- **Modules Used**:
  - Self-Structuring Engine (scan_structure, detect_redundancy, propose_reorg, apply_reorg)
  - Canonical layout rules and definitions
- **Artifacts Touched**:
  - docs/TECHNICAL_NOTES.md - Restructuring findings
  - docs/OPTIMIZATIONS.md - Reorganization proposals
  - Project structure (file moves, directory reorganization)

### Extractor Agent
- **Responsibilities**: Pattern extraction from user-provided repositories, integration proposals, pattern analysis
- **Modules Used**:
  - GitHub Pattern Extractor (analyze_repo, extract_patterns, propose_integrations)
- **Artifacts Touched**:
  - docs/TECHNICAL_NOTES.md - Extracted patterns
  - docs/OPTIMIZATIONS.md - Integration proposals
  - Repository snapshots (user-provided, temporary)

All agents operate with maximum autonomy inside the ANA MAX workspace.
They may modify, optimize, test, document, and evolve the system continuously.
Safety boundaries apply only to external actions.
