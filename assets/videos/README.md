# Video Links

Do not commit large video files to this repository.

Use this folder only for small metadata files or placeholders. Host public demos
on YouTube, GitHub Releases, or another external video host, then link them from
`README.md`, `index.html`, or `videos.html`.

Recommended public videos:

| Purpose | Length | Where to link |
|---------|--------|---------------|
| First proof demo | 60-90 seconds | README and website |
| QA lab workflow | 3-5 minutes | videos.html |
| Full test run | Optional long-form | GitHub Release or YouTube |

The repository should stay source-first: code, docs, tests, and small
public-safe assets only.
