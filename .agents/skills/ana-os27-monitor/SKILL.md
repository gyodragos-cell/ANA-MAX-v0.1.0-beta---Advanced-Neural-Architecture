# ANA OS27 Monitoring Skill

**Triggered.** Monitor OS27 telemetry and system health.

1. Check OS27 telemetry injection status
2. Monitor system vitals (CPU, RAM, GPU)
3. Analyze Frida instrumentation status

5. Report OS27 health metrics

Use OS27 telemetry module for all monitoring - direct system calls only when OS27 fails.
