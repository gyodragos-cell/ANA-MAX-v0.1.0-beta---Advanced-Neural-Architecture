# MCP Terms of Use (Trial Release)

**Scope**
This document applies to the *trial* version of the Model Context Protocol (MCP) distributed in the `ANA_MAX_GitHub_Release` repository. The MCP is the core of the **Advanced Neural Architecture** (English name) that powers ANA MAX.

**License**
MCP is released under the MIT License (see `LICENSE`). You are free to use, copy, modify, and distribute the software, provided the original copyright notice and license terms are retained.

**Offline‑only operation**
The MCP works **completely offline** – no internet connection is required. It can be used with any local AI model (e.g., Ollama, local LLM files, or any self‑hosted inference engine). The only requirement is that the model files are available on the host machine.

**Trial Limitations**
The following premium tools are **disabled** in this release:
- `desktop_capture`
- `live_desktop_viewer`
- `desktop_control_tool`
- `windows_insight_tool`
- `windows_deep_sight`
These features can be unlocked only after obtaining a Pro licence from the author. They are not loaded at runtime and are excluded from the public release bundle.
