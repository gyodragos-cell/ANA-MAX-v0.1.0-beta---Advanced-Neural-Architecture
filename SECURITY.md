# SECURITY.md

## Reporting Security Vulnerabilities

If you discover a security vulnerability in **ANA MAX**, please **do not** disclose it publicly.  Instead, follow these steps:

1. **Email** the security team at `gyodragos@gmail.com` with a detailed description of the issue, steps to reproduce, and any relevant logs or screenshots.
2. **Do not** post the issue on GitHub or any public forum until we have had a chance to investigate and respond.
3. We will acknowledge receipt of your report within 48 hours and work with you to resolve the issue.
4. Once a fix is ready, we will release a new version and update the CHANGELOG.

We appreciate responsible disclosures and will give proper credit to the reporter where appropriate.
