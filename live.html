Privacy boundary

What this GitHub Pages demo does—and does not—do.

LOCAL IN THIS TAB

No AI model, analytics SDK or server-side profile is required for this demo.

  • Display name is chosen by the visitor and kept only in session storage.
  • No external telemetry endpoint; this page sends no profile data to a backend.
  • No hidden access to accounts, files, passwords, messages or location.
  • Unsupported browser APIs display “Not available” rather than made-up values.
  • Screen and device values can be approximate or intentionally reduced by the browser.
Important distinction: a static GitHub Pages site cannot read a visitor’s Windows account name, exact system CPU load, full physical RAM usage, or list of running processes. Those require a separate local companion app installed and explicitly approved by each visitor. This page does not pretend to have that access.
