# ANA MAX OS v1 Release Notes

ANA MAX OS v1 packages the simulated ANA MAX AI Kernel runtime as
`ana_os_v1/`.

Highlights:

- Public-safe AI Kernel package.
- Simulated distributed runtime primitives.
- Model runtime, agent runtime, vector memory, DevTools, federation, and
  packaging helpers.
- Existing MCP tool runtime remains unchanged.
- Tool count remains 80 loaded tools.

Known limits:

- No real network transport.
- No real ML inference.
- No threads or async loops.
- Persistence is not production storage.
