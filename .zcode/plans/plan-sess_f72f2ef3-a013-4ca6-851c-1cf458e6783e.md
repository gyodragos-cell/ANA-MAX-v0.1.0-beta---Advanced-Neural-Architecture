# Plan: Duck.ai Proxy fiabil (fara Charles) + migrare in ana-manus

## Cauza reala a erorii 418 (demonstrata)
Abordarea istorica (capture tokenuri → replay prin `requests`) e **mortala** pe noul Duck.ai:
- `requests` are TLS/JA3 fingerprint diferit de Chromium → `418 ERR_CHALLENGE`
- Headerele `x-vqd-hash-1`/`x-fe-signals` sunt **recalculate de JS-ul Duck la fiecare request** — nu pot fi captate si reincarcate
- Chromium-ul bundle Playwright e fingerprintat ca bot → CAPTCHA „select all ducks"

**Solutia confirmata (test 4, status 200 + SSE curat):** Chrome REAL (`channel='chrome'`) + profil persistent `.duck_profile` + interceptare raspuns la nivel de retea. Browserul face singur toata criptografia; noi doar ascultam raspunsul. Zero Charles, zero token-uri manuale.

## Fluxul final (pastreaza obiceiul tau)
1. Dublu-click `START_DUCK_PROXY.bat` → omoara Ollama real (port 11434) → porneste proxy-ul → porneste ANA pe 8766
2. Se deschide **Chrome in fundal** (persistent) pe duck.ai — aici se „incalzeste" sesiunea (CAPTCHA doar prima data, apoi profilul e trust-uit)
3. ANA chat / dashboard se deschid in **Brave** (browserul tau default) → tu scrii in ANA
4. ANA trimite pe 11434 → proxy-ul tasteaza in Chrome-ul trust-uit pe duck.ai → prinde raspunsul SSE → il intoarce ca format Ollama

## Fisiere noi in `ana-manus` (totul la un loc, elegant)

### 1. `ANA_MAX/duck_proxy/duck_proxy_server.py` (NOU, implementare curata)
- **Pornire:** `launch_persistent_context` Chrome real (`channel='chrome'`), headless=False, profil `.duck_profile`, flag `--disable-blink-features=AutomationControlled`
- **Gata-pregatit:** navigheaza duck.ai o singura data, click „New Chat", asteapta textarea (selector confirmat: `textarea` cu placeholder „Reply...")
- **Detectare CAPTCHA (prima rulare):** daca apare „select all" / „containing a duck", avertizeaza in consola si asteapta rezolvare manuala (o singura data; profilul persistent memoreaza trust-ul)
- **Handler `/api/chat`:**
  - Tradu mesajele Ollama → concatenheaza `system` in ultimul mesaj user (pastreaza comportamentul istoric)
  - Tasteaza **doar ultimul mesaj user** in textarea (`press_sequentially` + Enter) — Duck pastreaza el istoricul conversatiei
  - Listener retea (`page.on("response")`) capteaza urmatorul `duckchat/v1/chat`, citeste `.text()` (SSE complet), parseaza toate liniile `data: {...}`, acumuleaza campurile `message`
  - Returneaza **un singur obiect** Ollama (`{model, message, done:true}`) — contract identic cu codul vechi ca ANA sa nu simta diferenta
- **Robustete / auto-vindecare:**
  - `threading.Lock` → serializeaza request-urile (un singur chat Chrome simultan)
  - Timeout 60s pe captura raspunsului
  - La timeout/eroare/CAPTCHA reaparut: click „New Chat" + retrimite o data
  - Thread watchdog: daca Chrome crapa, re-lanseaza contextul
- **Endpoint auxiliar `/api/tags`:** returneaza `duck-ai-model:latest` (ca Ollama sa detecteze modelul)
- Niciun `requests.post` catre duck.ai (sursa 418 a disparut); `x-vqd-4` nu mai e folosit
