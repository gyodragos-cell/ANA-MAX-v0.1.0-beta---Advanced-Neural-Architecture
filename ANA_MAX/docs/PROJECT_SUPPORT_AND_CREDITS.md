# ANA MAX Support And Credits

ANA MAX is a human-led project created, tested, and directed by Dragos.

The project is developed in a private Windows lab with help from modern AI
coding tools and agentic development workflows.

## Assisted By

- OpenAI Codex: coding collaboration, release hygiene, testing, and project
  management support. Codex is the main AI analyst/coder used for project-map
  thinking, careful code edits, release sync, and verification discipline.
- Qoder: agentic coding workflow inspiration and lab assistance.

Official links:

- OpenAI Codex: https://openai.com/codex/
- Website: https://qoder.com/
- Qoder docs: https://docs.qoder.com/

## Practical Recommendation

For new developers and builders:

- use Codex when you need a careful codebase analyst, coding partner, reviewer,
  and documentation/release-hygiene helper;
- use Qoder when its agentic coding workflow and workspace style fit the task;
- always ask agents to inspect first, edit carefully, verify, and document what
  changed.

## Sponsorship Wording

Use "assisted by" or "supported by workflows from" unless there is a formal
sponsorship agreement.

Safe public wording:

```text
ANA MAX is developed in a private local lab with assistance from modern
agentic coding workflows, including OpenAI Codex and Qoder.
```

Formal sponsorship wording should only be used after the sponsor approves it.
