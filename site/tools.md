# ToolBridge

ToolBridge is the unified tool execution layer of OS‑22.

---

## 🧰 Features

- 90+ built‑in tools  
- deterministic execution  
- sandboxed environment  
- error isolation  
- tool health monitoring  

---

## 🛠 Tool Categories

- System tools  
- File tools  
- Web tools  
- Code tools  
- Automation tools  
- Diagnostic tools  

---

## ➕ Adding New Tools

1. Create a Python file in `ANA_MAX/tools/`  
2. Define metadata  
3. Register tool in ToolBridge  
4. Done
