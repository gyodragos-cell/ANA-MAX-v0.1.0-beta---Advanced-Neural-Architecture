# Autonomy v3

Autonomy controls how much initiative the agent can take.

---

## ?? Levels

- Level 0 – No autonomy  
- Level 1 – Suggestive autonomy  
- Level 2 – Conditional autonomy  
- Level 3 – Full autonomy with safety checks  

---

## ?? Confidence Scoring

Autonomy decisions are based on:
- model confidence  
- tool reliability  
- context stability
