# Self‑Healing v2

Self‑Healing is the OS‑22 subsystem that detects and repairs runtime issues.

---

## 🩺 Detects

- tool failures  
- invalid states  
- corrupted context  
- infinite loops  
- missing dependencies  

---

## 🛠 Repairs

- resets tool state  
- rebuilds context  
- regenerates prompts  
- restarts execution
