# Install OS‑22

## 1. Requirements

- Python 3.10+
- pip
- Windows / Linux / macOS

---

## 2. Install dependencies

```
pip install -r requirements.txt
```

---

## 3. Run OS‑22

```
python scripts/run_os22.py
```

---

## Optional: Virtual Environment

```
python -m venv .venv
.\.venv\Scripts\activate
```
